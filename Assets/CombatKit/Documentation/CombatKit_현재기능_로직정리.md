# Combat Kit 현재 기능 및 핵심 로직 정리

작성 기준: 2026-10-26\
프로젝트: `CombatSystem` / Unity 6\
기능 범위: `Assets/CombatKit`의 플레이어 전투·이동, 일반 적과 보스, 카메라·연출, 훈련장, 에디터 도구

이 문서는 현재 코드의 실행 경로, 입력 연결, 프리팹과 설정 에셋을 기준으로 작성한 기능 설명서다. 기능별 동작과 시스템 사이의 연결을 중심으로 정리한다. 수치는 현재 기본 설정을 기준으로 하며, 캐릭터에 연결한 프로필이나 씬 설정에 따라 조정할 수 있다.

## 1. 전체 시스템 구조

플레이어는 `PlayerCharacter`가 입력과 각 기능 모듈의 실행 순서를 관리한다. 일반 적과 보스는 각각 독립적인 상태 머신으로 행동한다. 캐릭터 설정은 `ScriptableObject` 프로필에, 애니메이션과 모델·효과음은 `Content`에 분리되어 있다.

| 구성 | 역할 |
| --- | --- |
| 플레이어 | 전투 입력, 콤보, 체력, 이동, 회피, 공중 동작, 루트 모션을 모듈별로 처리 |
| 일반 적 | FSM으로 순찰·추적·공격·관찰·판단·후퇴·그로기를 관리 |
| 보스 | 투사체와 추적 돌진 패턴, 패링 누적과 그로기 공격 기회를 관리 |
| 전투원 등록 | `CombatRegistry`가 활성 플레이어·적·보스를 팀별로 관리하고 대상 탐색에 제공 |
| 입력 | `PlayerInputReader`가 Input System의 `Combat` 액션 맵을 읽고 `IPlayerInput`으로 전달 |
| 설정 | `PlayerProfile`과 적·보스별 Config 에셋에서 거리, 속도, 판정 구간 등을 조정 |

행동을 시작할 때는 사망, 피격, 회피, 매달림, 링크 점프 등 현재 동작을 확인한다. 공격 연결을 위한 입력은 버퍼에 보관하고, 실제로 전환 가능한 시점에 실행한다.

## 2. 콤보와 공격 연결

### 지상 콤보

- 기본 지상 콤보는 4단계로 구성된다.
- 공격 중 다음 입력을 받으면 현재 타격의 연계 가능 시점까지 보관한 뒤 다음 단계로 전환한다.
- 각 단계의 전환 시점과 블렌딩 시간을 따로 조절할 수 있다.
- 마지막 타격 중 다음 공격을 예약하면, 마지막 동작이 끝날 때 곧바로 첫 타격부터 새 콤보를 시작한다.
- 기본 콤보 클립의 공격 구간을 사용하고 현재 대기 모션으로 블렌딩한다. 잘라낸 클립에서도 원본 진행률을 환산해 연계·판정 시점을 맞춘다.
- 마지막 타격의 도약은 발 높이 궤적을 사용해 실제 캐릭터 이동에 반영한다.

### 지상 공격 사이의 연계

일반 공격, 관통 돌진, 띄우기, 반격과 후속 공격을 서로 연결할 수 있다. 연결은 단순히 버튼을 누르는 순간 애니메이션을 바꾸는 방식이 아니라, 공격별 전환 구간과 입력 버퍼를 함께 사용한다.

| 연결 종류 | 현재 동작 |
| --- | --- |
| 일반 콤보 → 다른 공격 | 연계 요청을 저장하고 지정된 진행도에서 전환 |
| 일반 콤보 → 어퍼 | 현재 콤보의 연계 시점에서 플레이어와 적을 띄우는 공격으로 전환 |
| 관통 돌진 → 후속 공격 | 돌진이 적에게 적중하면 후속 입력 창을 열고, 입력 시 올려베기 형태의 연결 공격 실행 |
| 후속 공격 → 지상 콤보 | 후속 공격의 연계 시점에서 기본 콤보 첫 타격으로 연결 |
| 패링 반격 → 후속 공격 | 자동 반격 중 새 공격 입력을 받으면 연결 공격을 예약 |
| 회피 → 공격 | 회피의 공격 전환 가능 구간에서 보관한 공격 입력 실행 |

관통 돌진은 공격 모션의 지정 시점부터 전진한다. 돌진 중에는 적의 몸체 충돌을 잠시 제외하고, 실제 이동한 구간 전체를 검사해 적을 타격한다. 끝나거나 중단되면 충돌을 복구한다.

### 공중 콤보

- 어퍼로 직접 함께 뛰어오르거나, 먼저 적을 띄운 뒤 추격 도약으로 공중 전투를 시작한다.
- 공중 콤보는 4단계로 연결된다. 각 단계는 실제 공격 진행도에 맞춰 다음 타격으로 넘어간다.
- 어퍼를 시작한 입력과 공중 후속 공격 입력을 구분해, 하나의 클릭으로 두 공격이 동시에 예약되지 않게 한다.
- 공중 피격은 실제로 떠 있는 적에게 적용한다. 피격 시 적의 체공을 갱신하고, 전용 공중 피격 모션을 재생한다.
- 플레이어의 공격 전진과 적의 이동을 함께 조정해 서로 지나치게 겹치지 않도록 한다. 적이 벽에 막혀 밀리지 못하면 플레이어의 접근량도 제한한다.
- 공중 관통 대시는 이동 거리를 제한하고, 추가 입력으로 공중 콤보를 이어갈 수 있다.
- 공중 콤보가 끝나면 낙하와 착지 상태로 이어지고, 착지 직전·직후의 공격 입력은 지상 공격으로 연결할 수 있다.

### 내려찍기와 바운드 연계

공중 내려찍기는 준비 → 낙하 → 착지 순서로 진행한다. 현재 사용 애니메이션은 `Attack_Air_To_Floor_03` 계열의 시작·반복·종료 클립이다.

- 일반 공격과 별도의 위·아래 높이 조건으로 대상 적을 찾는다.
- 현재 범위는 수평 10m, 위쪽 2m, 아래쪽 30m다.
- 유효한 락온 대상을 우선하고, 없으면 조건을 만족하는 적 중 수평 거리가 가장 가까운 대상을 선택한다.
- 발동 순간의 적 위치를 저장하고, 해당 위치를 향해 수평 이동하면서 내려찍는다.
- 수평 최대 속도는 18m/s이며, 목표까지의 거리와 예상 바닥 높이를 이용해 낙하 시간을 맞춘다.
- 대상이 없으면 수직 낙하한다. 벽에 부딪히면 수평 접근을 멈추고 낙하를 계속한다.
- 낙하 경로의 공중 적과 착지 충격 범위의 적을 검사한다. 한 번의 내려찍기에서 같은 대상에게는 한 번만 피해를 준다.
- 착지 충격 반경은 2.5m이며, 착지 후 0.35초부터 입력에 따라 지상 공격을 연결할 수 있다.

공중 마무리 타격과 연속 내려치기 피격은 적의 착지 바운드를 예약할 수 있다. 바운드는 같은 다운 연계에서 한 번만 허용하며, 적이 다시 떠 있는 동안 후속 공격을 연결할 수 있다.

### 차지 강공격

지상 기본 공격 입력은 누른 시간으로 구분한다. 0.3초 미만으로 눌렀다 떼면 일반 공격을, 0.3초 이상 유지하면 차지 공격을 준비한다.

- 차지는 준비·유지·발동 동작으로 나뉜다.
- 버튼을 유지하는 동안 차지 상태를 유지하고, 버튼을 놓으면 공격을 발동한다.
- 피해 배율은 차지 시간에 따라 증가한다. 현재 기본 배율은 2배에서 5배다.
- 최대 피해에 도달하는 시간은 5초다. 그 이후에도 자세는 유지할 수 있지만 피해 배율은 더 증가하지 않는다.
- 발동 공격의 전진 타격과 후속 내려찍기는 각각 별도의 판정 구간을 사용한다.

### 공격 방향과 대상 선택

일반 공격과 지상 스킬은 시작할 때 주변 적을 찾아 수평 방향을 맞춘다. 기본 탐색 거리는 10m, 높이 허용치는 ±2m다. 락온 상태에서는 지정 대상을 우선한다. 공중 내려찍기는 앞서 설명한 전용 높이 조건을 사용한다.

## 3. 회피

회피 방향은 카메라 기준 이동 입력으로 정한다. 방향 입력이 있으면 그 방향으로 돌아서 전방 회피하고, 입력이 없으면 현재 정면을 유지한 채 뒤로 회피한다.

- 달리는 중 방향 입력과 함께 회피하면 달리기 연결용 회피 모션을 사용한다.
- 회피 이동은 클립의 수평 루트 모션에 거리 배율을 적용한다.
- 회피 중 들어온 공격은 피해와 피격 애니메이션을 발생시키지 않는다.
- 회피로 흘린 접촉도 처리 완료로 기록해 같은 휘두르기에 회피 종료 직후 다시 맞지 않게 한다.
- 지상 콤보는 단계별 회피 취소 가능 시점에서 회피로 전환할 수 있다.
- 회피 중 받은 공격 입력은 보관하고, 회피 진행률에 따라 공격으로 연결한다.
- 공중 회피가 끝나면 공중 이동 또는 착지 동작으로 이어진다.

저스트 회피는 회피 시작 후 짧은 시간 안에 실제 공격 접촉을 피했을 때 성립한다. 현재 판정 시간은 0.2초이며, 회피 한 번당 한 번만 인정한다. 성공하면 슬로 모션과 카메라 줌아웃 연출을 재생한다.

## 4. 패링과 그로기

### 일반 적 패링

패링은 준비 동작을 시작한 뒤, 유효 시간 안에 적의 활성 공격 판정이 플레이어에게 도달했을 때 성립한다. 입력만으로 성공 처리하지 않고 실제 공격 접촉을 기준으로 확인한다.

1. 패링 준비 동작을 시작하고 판정 창을 연다.
2. 공격 접촉 시 판정 시간, 플레이어 상태와 공격자 방향을 검사한다.
3. 성공하면 피해를 막고 플레이어가 즉시 반격 애니메이션을 재생한다.
4. 적은 무기가 튕기는 동작 이후 그로기 상태로 전환한다.
5. 플레이어는 반격 중 추가 공격 입력으로 후속 연결 공격과 지상 콤보를 이어갈 수 있다.

현재 패링 입력 창은 0.24초이며, 공격자가 플레이어 정면 기준 좌우 80도 안에 있어야 한다. 성공한 패링 입력은 한 번만 소비한다. 성공 시 슬로 모션, 카메라 줌인, 금속 충돌음과 콘솔 로그가 함께 발생한다.

### 일반 적의 그로기 누적

| 구분 | 현재 기본 동작 |
| --- | --- |
| 패링 성공 | 그로기 누적 횟수 1 증가 |
| 누적 한도 전 | 튕김 동작 이후 1.2초의 짧은 그로기 |
| 4회 누적 | 튕김 동작 이후 4초의 큰 그로기 |
| 큰 그로기 종료 | 누적 게이지 초기화 후 전투 복귀 |

그로기 중의 추가 타격은 피해를 적용하면서 그로기 상태를 유지한다. AI 모니터에서 누적량, 현재 그로기 상태와 남은 시간을 확인할 수 있다.

### 보스 패링

보스는 투사체와 근접 공격에 대한 패링 처리를 갖는다. 투사체는 플레이어 가까이에서 별도의 슬로 모션 판정 창을 제공한다. 성공 입력은 일반 공격 입력과 중복으로 소비하지 않도록 관리한다.

보스의 공격 기회는 패링 누적과 연결되어 있다. 4회 성공하면 10초간 그로기에 들어가며, 이때 플레이어의 공격으로 체력을 깎을 수 있다.

## 5. 타격 판정과 피격·체력

### 공격 판정

공격 판정은 애니메이터의 실제 상태와 진행률을 읽어 열린 구간에서 수행한다. 애니메이션 전환 중에는 해당 공격으로 들어가는 다음 상태도 확인한다.

- 무기, 발차기, 공중 공격 등 동작에 맞게 박스·구·캡슐 범위 검사를 사용한다.
- 빠르게 이동하는 공격은 이전 위치부터 현재 위치까지 검사해 중간 구간의 타격 누락을 줄인다.
- 공격 시퀀스와 타격별 명중 목록을 관리해 여러 콜라이더가 있는 적에게도 같은 타격의 피해가 중복되지 않게 한다.
- 의도된 다단 공격은 타격별 명중 목록을 분리한다.
- 타격 구간이 끝나면 복귀 모션 중에는 새 피해가 발생하지 않도록 판정을 닫는다.

### 플레이어의 체력과 피격

플레이어는 최대 체력과 현재 체력을 보유하고, 공격 종류에 따라 피해를 받는다. 기본 프로필은 체력 100, 약공격 피해 10, 강공격 피해 20이다.

- 회피나 패링 성공 여부를 먼저 확인하고, 피해가 성립한 경우 체력을 감소시킨다.
- 공격 중에는 피해를 받더라도 현재 공격 모션을 유지하는 경직 저항을 적용한다. 패링 준비 동작은 이 보호에서 제외한다.
- 공격 상태가 아닐 때 피해를 받으면 공격 종류에 맞는 피격 애니메이션을 재생한다.
- 다운이 적용되면 누운 상태를 유지하다가 이동 입력 방향에 맞춰 기상한다.
- 체력이 0이면 행동을 종료하고 사망 애니메이션과 전용 카메라 연출을 실행한다.
- 사망 후 재시작 입력으로 현재 씬을 다시 로드해 부활한다.

### 적의 피격과 밀려남

적은 일반 경직, 지상 콤보 피격, 관통 연속 피격, 공중 피격, 넉다운과 기상 반응을 구분한다.

- 지상 콤보는 단계별 피격 모션으로 공격자 반대 방향으로 밀려난다.
- 세 번째 타격에는 후속 공격을 위한 추가 밀림을 적용한다. 현재 설정은 공격자와 약 4m 간격을 목표로 하되 추가 밀림에 상한을 둔다.
- 마지막 지상 타격은 밀려나는 지상 피격으로 연결한다.
- 일반 지상 콤보를 맞는 동안 적이 이미 공격 중이면 체력 피해를 적용하고 현재 공격을 유지한다.
- 관통 공격은 연속 피격 모션으로, 띄우기 공격은 공중 피격으로 연결한다.
- 공중 타격은 전용 피격 모션을 사용하고, 넉백 이동과 중력·바닥 충돌을 함께 처리한다.
- 넉다운 후 기상·구르기는 수평 이동과 지면 높이 보정을 적용해 실제 위치 변화로 이어진다.

`EnemyKnockbackMotion`은 속도, 중력, 이동 경로 충돌과 접지를 계산한다. 애니메이션 포즈와 실제 이동을 분리해 날아가거나 떨어지는 동안에도 지면에 도달할 수 있게 한다.

## 6. 일반 적 AI

일반 적은 다음 상태를 사용하는 FSM으로 움직인다.

| 상태 | 역할 |
| --- | --- |
| Idle | 대기와 감지 |
| Patrol | 생성 위치 주변 순찰 |
| Chase | 플레이어까지 경로를 찾아 접근 |
| Attack | 오프닝 공격 또는 근접 콤보 실행 |
| Observe | 전투 위치를 바꾸며 플레이어 관찰 |
| Decision | 현재 상황과 가중치로 다음 행동 결정 |
| Retreat | 후퇴 후 전투 흐름에 복귀 |
| Hit / Groggy | 피격 반응 또는 패링에 따른 행동 제한 |

주요 전투 흐름은 `Chase → Attack → Observe → Decision → 다음 행동`이다.

### 이동과 장애물 우회

추적, 순찰, 관찰과 후퇴는 `EnemyNavigation`의 `NavMeshAgent`를 통해 이동한다. 도달 가능한 NavMesh 위치와 완전한 경로를 확인한 뒤 목적지를 설정한다.

- 벽이 있으면 베이크된 경로를 따라 우회해 접근한다.
- 공격 사거리 안에 들어와도 대상과 높이가 맞고 사이에 지형이 없는지 추가로 검사한다.
- 공격, 피격과 넉백 중에는 NavMesh 이동을 중지해 애니메이션 또는 전용 이동 코드가 위치를 제어한다.
- 전투 이동이 끝나면 발밑 가까운 유효 NavMesh에 다시 연결한다.
- 유효한 NavMesh를 찾지 못하면 이동을 정지하고 경고를 남긴다.

### 공격

적의 첫 공격은 오프닝 점프 공격이다. 시작할 때 플레이어를 바라보고 거리에 맞춰 도약량을 조정하며, 도약 중에는 방향을 유지한다.

이후 근접 콤보는 1~3단계의 약공격과 4단계의 강공격으로 구성된다. 진행 단계와 종료는 실제 애니메이터 상태·진행률로 판단하며, 공격 중에는 설정된 회전 속도로 플레이어를 바라본다. 콤보를 완주하면 관찰 상태로 넘어간다.

### 관찰과 판단

관찰은 공격 사이에 플레이어를 견제하며 위치를 바꾸는 상태다.

- 플레이어 정면 기준 좌우 60도, 거리 2.5~4m 안에서 도달 가능한 위치를 선택한다.
- 선택한 위치를 월드 좌표로 저장하고 그 지점을 향해 이동한다.
- 플레이어가 움직이거나 돌아도 저장한 목적지를 매 프레임 따라 옮기지 않는다.
- 목적지에 도착하면 같은 프레임에 다음 위치를 선택해 이동을 이어간다.
- 기존 목적지가 허용 거리·각도를 크게 벗어난 경우에는 재선택 간격을 적용한다.
- 이동 중에도 플레이어를 바라보고, 로컬 이동 방향과 관찰 전용 애니메이션 속도를 갱신한다.

기본 추적 속도는 4m/s, 관찰 속도는 1.8m/s다. 기본 관찰 시간이 지나면 판단 상태에서 공격 재접근, 관찰 유지, 재배치, 후퇴 중 다음 행동을 고른다. 플레이어가 공격 중인지에 따라 공격 선택 가중치도 달라진다.

## 7. 보스 전투

보스는 대기 → 패턴 실행 → 회복·대기의 흐름으로 행동하고, 두 패턴을 번갈아 선택한다. 패링 누적이 가득 차면 그로기 상태로 전환한다.

### 투사체 패턴

- 플레이어를 향해 던지기 애니메이션을 시작한다.
- 애니메이션이 투척 시점에 도달한 뒤, 포즈가 갱신된 `LateUpdate`에서 손 쪽 발사 위치를 읽는다.
- `Sphere0` 프리팹을 생성하고 Rigidbody 속도로 플레이어 방향에 발사한다.
- 발사 크기는 프리팹의 원래 크기를 사용한다.
- 투사체가 가까워지면 실제 시간 기준 약 2초의 패링 창을 열고 시간을 느리게 한다.
- 패링 성공 시 플레이어를 투사체 쪽으로 맞추고 전용 반응을 재생하며, 공은 물리 파편으로 분해된다.
- 패링 성공, 명중, 충돌 또는 소멸 시 투사체를 처리 완료로 표시하고 시간 배율을 복구한다.

### 추적 돌진과 점프 공격

웅크림 → 질주 시작 → 추적 돌진 → 점프 → 착지 → 회복 순서로 진행한다.

- 돌진은 플레이어를 추적하되 최소 회전 반경으로 방향 전환량을 제한한다.
- 최대 돌진 거리와 최대 시간을 함께 검사한다.
- 근접 추적 종료 거리 안으로 들어오면 목표 위치를 고정하고 점프 공격으로 이어진다.
- 이동 중 벽을 검사하고, 장애물에 막히거나 돌진 한도를 넘으면 회복으로 넘어간다.
- 돌진 경로와 착지 충격 범위에 각각 공격 판정을 적용한다.
- 점프 시작·비행·착지 단계에 맞춰 애니메이션을 연결하고 착지 포즈의 지면 높이를 보정한다.

### 그로기 공격 기회

보스의 피해 허용 조건은 그로기 상태다. 패링을 4회 누적하면 10초간 공격할 수 있으며, 시간이 끝나면 누적량을 초기화한다. 그로기 진입 시 남아 있는 투사체도 정리한다.

## 8. 플레이어 이동과 지형 액션

### 기본 이동과 점프

플레이어는 실제 화면을 출력하는 카메라 방향을 기준으로 걷고 달린다. 기본 속도는 걷기 3m/s, 달리기 9m/s이며, 큰 방향 전환에는 달리기 턴 동작을 사용한다.

일반 점프와 추가 공중 점프를 지원한다. 공중에서는 이동 방향을 조절하고, 접지 상태에 맞춰 낙하·착지 애니메이션으로 넘어간다. CharacterController가 이동과 지형 충돌을 처리한다.

### 링크 점프

NavMeshLink의 활성 끝점 가까이에서 점프하면 연결된 반대편으로 이동한다.

- 링크 폭, 시작점과의 거리, 높이 차이와 양방향 여부를 확인한다.
- 끝점의 지면 위치를 캐릭터 캡슐 중심 위치로 변환한다.
- 도약 → 포물선 비행 → 착지 단계와 애니메이션을 연결한다.
- 이동 중 지형에 막혀 계획 경로에서 벗어나면 링크 이동을 종료한다.

훈련장의 링크 접근 지점에는 위치를 알아볼 수 있는 파란색 표시를 배치한다.

### 벽 달리기

- 공중에서 달리기 입력을 유지하고 유효한 옆벽이 있으면 벽을 따라 달린다.
- 벽과의 간격, 이동 방향, 수평 속도, 앞쪽 공간, 벽의 연속성과 감지 유지 시간을 검사한다.
- 부착하면 벽 달리기 반복 모션으로 진입하고, 최대 2초 동안 유지한다.
- 벽이 끝나거나 장애물이 나타나면 공중 이동으로 넘긴다.
- 점프로 벽에서 이탈하면 공중 이동·낙하·착지로 연결하고 입력으로 방향을 조절할 수 있다.
- 충분히 벽을 달리면 추가 공중 점프 기회를 한 번 회복한다.
- 착지 전 다른 벽으로 이어 붙을 수 있으며, 재부착에는 대기 시간과 횟수 등의 제한을 적용한다.

### 벽 모서리 매달리기와 올라가기

납도 상태에서 매달리기 입력을 받으면 앞쪽 벽과 윗모서리를 탐색한다. 입력을 짧게 보관해 점프 중 잡을 수 있는 시점을 연결한다.

- 벽 방향과 손이 닿을 높이를 확인한 뒤 잡기 모션으로 진입한다.
- 대기 모션에서 몸의 높이와 손 목표점을 벽에 맞추고 IK로 보정한다.
- 좌우 입력에 맞춰 모서리를 따라 이동하며 벽과 모서리 위치를 다시 확인한다.
- 위쪽 이동 입력으로 벽 위에 올라갈 수 있다. 올라갈 바닥과 몸이 지나갈 공간을 먼저 검사한다.
- 올라가기 애니메이션의 진행률에 맞춰 몸을 올리고 앞으로 옮긴 뒤 지상 대기로 연결한다.
- 내려오기 입력으로 손을 놓으면 낙하와 착지로 이어진다.

### 철봉 매달리기와 스윙

철봉은 `HangRail`을 대상으로 하며, 양손을 사용할 수 있는 납도 상태에서 잡는다.

- 아래에서 도약해 잡기, 높은 쪽에서 짚고 내려와 잡기, 공중에서 잡기를 구분한다.
- 거리·높이·실제 팔 도달 범위와 이동 경로를 검사해 접근을 계획한다.
- 시작 모션의 손 접촉 시점에 맞춰 철봉에 도달하고, 실제 손 접촉을 확인한 뒤 매달림으로 전환한다.
- 손 위치를 철봉에 고정하고, 몸의 움직임은 잡은 손을 기준으로 보정한다.
- 앞뒤 입력으로 스윙을 키우고 입력이 없으면 감쇠시킨다. 전체 스윙 각도에는 90도 상한을 둔다.
- 정지 상태에서 내려오기 입력을 받으면 손을 놓고, 스윙 중에는 운동량을 이용한 점프 이탈이 가능하다.
- 잡기에 실패하거나 이탈할 때 기존 운동량을 공중 이동에 전달한다.

### 경사면 슬라이딩과 높은 낙하 착지

경사가 조건을 만족하면 슬라이딩의 시작·유지·종료 단계를 연결한다. 경사 방향으로 가속하고, 앉은 자세의 골반·발 높이를 경사면에 맞춰 보정한다.

높은 곳에서 떨어질 때는 최고점과 착지점의 높이 차이를 기록한다. 일반 더블 점프보다 높은 낙하 조건을 만족하면 착지 구르기를 재생한다. 구르기는 착지 시 바라보던 방향으로 전진하며, 클립의 회전이나 복귀 이동이 캐릭터를 원형으로 돌리지 않도록 수평 이동을 제한한다.

### 발도와 납도

칼을 넣고 빼는 애니메이션의 지정 시점에 무기를 손과 허리 부착 위치 사이에서 전환한다. 납도 상태에는 비무장 대기·걷기·달리기 모션을 사용한다.

납도 중 공격 입력을 받으면 발도 동작을 먼저 수행한다. 발도 중 입력은 바로 이어지는 공격으로 예약하지 않는다.

## 9. 애니메이션과 실제 이동의 동기화

루트 모션과 코드 이동은 현재 행동에 맞춰 역할을 나눠 적용한다.

| 행동 | 이동 제어 |
| --- | --- |
| 일반 이동·점프 | 이동 속도와 중력을 코드에서 계산 |
| 일반 공격·회피 | 해당 동작의 수평 루트 모션 사용 |
| 어퍼·추격 도약 | 공중 전용 이동과 높이 제어 |
| 공중 콤보 | 수평 루트 모션과 별도의 체공·낙하 제어 |
| 공중 내려찍기 | 목표 위치를 향한 수평 이동과 낙하를 코드에서 함께 계산 |
| 관통 돌진 | 판정 시점부터 거리·시간 기준 전진 |
| 링크·벽·철봉 이동 | 해당 지형 동작이 이동을 맡고 애니메이션 진행도와 동기화 |
| 적의 피격·넉백 | 피격 포즈와 넉백 속도·중력·접지 처리 |

발 높이와 몸 위치 보정은 공격·착지·기상 등 상태별로 적용한다. 이동을 이미 코드가 처리하는 동작에서는 같은 프레임의 루트 모션이 다시 더해지지 않도록 한다.

전투에 사용하는 플레이어·적·보스 애니메이션은 `Content/Animations` 아래에 구분해 관리하며, Animator의 실제 진행도를 공격 연결과 판정의 공통 기준으로 사용한다.

## 10. 카메라와 전투 연출

### 카메라

- 자유 시점과 락온 전용 Cinemachine 카메라를 전환한다.
- 락온은 일반 적과 보스를 대상으로 하며, 플레이어와 대상을 함께 담는 타겟 그룹을 사용한다.
- 락온 획득 거리와 유지 거리를 구분한다. 기본 값은 각각 20m, 25m다.
- 강공격 중에는 위치·조준 댐핑을 조정해 급격한 카메라 움직임을 완화한다.
- 일부 공격 연출은 입력 순간이 아니라 실제 공격 진행과 타격 시점을 기준으로 카메라 거리를 조정한다.
- 패링과 저스트 회피는 각자의 시간·줌 연출을 재생하고 종료 후 원래 값을 복구한다.
- 사망 시 전용 카메라가 쓰러지는 모습을 보여 준다.

커서는 플레이어의 커서 관리 컴포넌트에서 잠근다. 잠금 해제, 화면 클릭 시 재잠금, 포커스 변경과 메뉴 열림 상태를 처리하며, 열린 메뉴를 소유자별로 추적한다.

### 검 궤적과 효과음

검 궤적은 칼날 시작점과 끝점의 위치를 연속 샘플링해 리본 메시로 그린다. 실제 휘두름 판정 구간에 맞춰 생성하고, 공격이 바뀌면 이전 궤적과 분리한다. 시간이 지난 샘플은 사라지며 잔상을 만든다.

플레이어와 적의 휘두르기 소리는 공격 판정 시점에 맞춰 재생한다. 공격 시퀀스와 타격 번호를 사용해 느린 재생이나 애니메이션 전환 중에도 같은 타격 소리가 중복되지 않도록 한다. 패링 성공에는 별도의 충돌음을 재생한다.

발자국 소리는 플레이어와 적의 실제 이동·접지 상태를 확인한 뒤, 현재 이동 클립의 왼발·오른발 접촉 시점에 맞춰 재생한다. Stone 계열 음원을 사용하고, 연속 재생 간격과 음원 선택을 관리한다.

## 11. 훈련장과 UI·디버깅

### 콤보 훈련장

`ComboPracticeGround`는 더미 콤보 연습, 1대1 실전, 다대일 전투와 이동 기능을 시험할 수 있는 구역으로 구성된다.

- 더미는 실제 적 피격·밀림·공중 반응을 사용하면서, 피해를 받을 때 체력을 회복해 반복 연습할 수 있다.
- 더미 모니터는 적중 수, 연속 적중과 누적 피해 등을 기록한다.
- 콤보 연습 UI는 실제 공격 종류, 단계와 `AttackSequence`를 확인해 순서대로 성공한 아이콘을 지운다.
- 연습 과정은 지상 콤보, 띄우기·추격·공중 연계, 관통 후속 공격·지상 콤보의 세 종류로 순환한다.
- 중간에 순서가 틀리거나 연결이 끊기면 진행도를 초기화한다.
- 콤보 적중 표시는 실제 피해 이벤트를 기준으로 올라가고, 크기·색상·움직임으로 연속 타격을 강조한다.

### 실전과 다대일 훈련

1대1 구역은 플레이어가 진입했을 때 상대 AI와 무기 판정을 활성화한다. 구역을 벗어나면 전투를 종료하고, 상대가 쓰러지거나 구역을 벗어나면 다시 연습할 수 있도록 재배치한다.

다대일 구역은 추가·제거 버튼으로 적 수를 조정한다. 최대 20명 범위에서 활성 슬롯을 관리하며, 여러 적의 공격 속에서 콤보와 회피·패링을 시험할 수 있다.

### 이동 훈련장과 씬 이동

`LocomotionTraining`은 점프, 벽 달리기, 철봉, 경사면 등 이동 동작을 연속으로 연습하는 별도 씬이다.

- 콤보 훈련장의 제단에서 이동 훈련장으로 진입한다.
- 제단 상호작용은 공통 `InteractionInput`을 사용하며 현재 상호작용 키는 F다.
- 시작 지점의 귀환 제단으로 돌아올 수 있고, 코스 완료 시 완료 안내 후 콤보 훈련장으로 자동 복귀한다.
- 추락·사망·재시작 요청 시 씬을 다시 로드해 이동 상태를 초기화한다.
- 씬 전환은 입력 정지, 페이드, 비동기 로드와 도착 위치 배치를 처리한다.

### 상태 UI와 FSM 그래프

플레이어 상태 UI는 이름, HP와 현재 상태를 표시한다. 적 모니터는 이름, HP, 현재·이전 상태, 상태 유지 시간, 감지·공격 거리와 그로기 정보를 보여 준다. 보스 모니터는 패턴과 그로기 진행 상황도 표시한다.

FSM은 상태마다 `ENTER / EXECUTE / EXIT` 로그를 남긴다. 같은 상태의 연속 실행은 횟수로 묶고 최근 기록을 보관한다.

`Tools > Combat Kit > FSM Graph` 창에서는 상태와 조건을 노드 형태로 볼 수 있다. 플레이 중 현재 상태와 최근 진입 상태를 강조하고 Blackboard·Inspector에서 판단 값과 로그를 확인한다. 실제 행동은 FSM 코드가 실행하며, 그래프의 노드 배치는 상태를 설명하고 관찰하는 용도다.

## 12. 재사용 구조와 관리 위치

Combat Kit는 `Assets/CombatKit` 안에 코드, 설정, 프리팹과 콘텐츠를 보관한다. `.unitypackage`로 내보내 다른 프로젝트에 가져오면 그 프로젝트 안의 독립 복사본으로 사용할 수 있다.

| 경로 | 내용 |
| --- | --- |
| `Runtime/Player` | 플레이어 전투, 이동, 피격, 지형 액션과 연출 |
| `Runtime/Enemy` | 일반 적 FSM, NavMesh 이동, 공격과 피격 |
| `Runtime/Boss` | 보스 상태, 패턴, 투사체와 그로기 |
| `Runtime/Input`, `Runtime/Core` | 입력 연결과 전투원 등록 |
| `Runtime/Data` | 기능별 설정 에셋의 자료형 |
| `Runtime/Training`, `Runtime/UI` | 훈련 구역, 연습 UI와 모니터 |
| `Content` | 프리팹, 씬, 애니메이션, 설정과 사용 콘텐츠 |
| `Editor` | 스폰, NavMesh 베이크, FSM 그래프와 내보내기 도구 |
| `Documentation` | 설치 안내, 의존성 정보와 기능 설명서 |

주요 조정 위치는 다음과 같다.

| 조정 목적 | 설정 위치 |
| --- | --- |
| 플레이어 콤보 연결·공격 조준 | `PlayerProfile.combat` |
| 이동·점프·회피 | `PlayerProfile.locomotion`, `dodge`, `linkJump` |
| 체력·패링·차지 공격 | `PlayerProfile.health`, `parry`, `powerAttack` |
| 공중 콤보·대시·내려찍기 | `PlayerProfile.airCombo` |
| 공격별 타격 구간·범위 | `PlayerWeaponHitboxConfig` |
| 적 감지·공격·관찰·그로기 | `EnemyCombatConfig` |
| 적의 피격·밀림·바운드 | `EnemyDamageReactionConfig`, `EnemyKnockbackMotionConfig` |
| 보스 패턴·투사체 | `BossCombatConfig`, `BossPattern1Config`, `BossPattern2Config`, `BossProjectileConfig` |
| 벽·철봉·모서리·경사면 액션 | 플레이어의 해당 이동 컴포넌트 |

에디터 메뉴에서 캐릭터·카메라 스폰, 현재 씬 NavMesh 베이크와 FSM 그래프를 실행할 수 있다. 패키지 내보내기는 에디터 코드에서 `CombatSystem.EditorTools.CombatKitExporter.ExportTo(outputPath)`로 실행한다. 내보내기 도구는 `CombatKit` 밖의 `Assets` 의존성을 검사한다. 다른 프로젝트에서 사용할 때 필요한 Input System, Cinemachine, AI Navigation, UGUI와 URP 패키지 정보는 `Documentation/INSTALL.txt`와 `DependencyVersions.json`에서 관리한다.
